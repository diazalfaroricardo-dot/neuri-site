# Glosario de palabras prohibidas (copy de Neuri)

Para el revisor del equipo. Fuente de la regla: Unbounce 2024 (textos a nivel de 5.º a 7.º grado convierten casi el doble). Espejo en Mission Control: copy/glosario-prohibidas.

## Reglas
- Subtítulo del hero: 20 palabras o menos.
- Cualquier frase: 20 palabras o menos; si pasa, se parte en dos.
- Nombra lo que la persona hace o ve, no cómo está hecho el sistema.
- Los datos no cambian al simplificar: precios, plazos, garantías y promesas se quedan igual.
- Nombres de marca (Instagram, Claude, ChatGPT, Stripe) sí se pueden usar.

## No escribir → escribir
| No escribir | Escribir |
|---|---|
| API, API oficial de Meta / Meta's official API | conexión oficial de Meta / Meta's official connection |
| DMs, «DM» como verbo | mensajes / messages; «te manda» / sends |
| conector, conector personalizado, MCP, URL del conector | link para tu asistente / link for your assistant |
| flujos, flujo de prospección, workflow | pasos, respuestas, plan de ventas |
| Console (Search Console sin explicar) | la herramienta de Google para tu sitio (Search Console) |
| «$ neuri run reply» o cualquier comando de terminal | lo que pasa, en palabras: «Neuri contesta» |
| next orbit, órbita | lo que sigue, próximamente |
| suite de agentes, agentes de IA (en subtítulos) | lo que hace: contesta, cobra, lleva tus cuentas, hace tus posts |
| leads, enriquecimiento, CRM, ERP (sin explicar) | clientes posibles, datos de cada cliente, tu sistema de ventas |
| integrados a tus sistemas, onboarding, escalamiento | conectados a lo que ya usas, alta, «te lo pasa a ti» |
| antique mall, swap meet, sales tax en español sin explicar | en español para hispanos en EE. UU. (opción B, 24-nov): se dicen con su explicación, p. ej. «el impuesto de tu estado (sales tax)» |

## Cómo revisar
1. Cuenta las palabras del subtítulo del hero (máx. 20).
2. Busca frases de más de 20 palabras y pártelas.
3. Busca cada palabra de la tabla en el diff (ES y EN).
